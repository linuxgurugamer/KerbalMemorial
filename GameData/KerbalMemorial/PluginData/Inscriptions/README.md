# Memorial inscriptions

Place UTF-8 `.txt` files in the `Deceased` folder for confirmed fatalities and in the `Missing` folder for still-missing crew. Each nonblank message line is a candidate within its own status pool. Markdown headings such as `### **Short plaque inscriptions**` and list prefixes are ignored. Files in this parent folder are not read. Previously assigned messages are preserved, except for the old fixed missing fallback, which is replaced when a random missing message is available. No message files are supplied here.
